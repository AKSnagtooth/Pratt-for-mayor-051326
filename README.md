# Pratt for Mayor 2026 — Landing Pages (Mockups)

Mockup landing pages for the Snagtooth × Pratt for Mayor 2026 campaign.

## Pages

- `index.html` — Homepage with countdown timer and drop box finder. Where most paid ads send people.
- `ballot.html` — Ballot-action focused page. ZIP-search for drop boxes. For ballot-action Search ads.
- `save-la.html` — Persuasion-focused page. Fire story, plan, testimonials. For top-of-funnel awareness ads.

## Brand

- Black `#0A0A0A` primary background
- Orange `#F76B1C` accent (matching campaign brand)
- Playfair Display serif headlines, Inter sans body
- Mobile-first, CRO-optimized

## Status

**These are mockups for the kickoff meeting.** Forms submit to placeholder UI states. Drop box data is mocked for ~8 LA ZIPs. Pixel installation placeholders are in the HTML comments — uncomment and add IDs before launch.
